# Project background

I developed Course Planner with a university senior design team. Team members received individual copies for their GitHub portfolios, and I confirmed permission to share the team-written code on 29 October 2026. I maintain this portfolio copy. I acknowledge my teammates' work on the original application and the instructor's project scaffolding; this repository does not claim that I wrote the entire application.

The recovered team history records course-search DTO and repository-query work under my name, along with merge work. Code was also pushed centrally, so commit authorship is not a complete record of individual contributions. My portfolio work has focused on parser correctness, copied schedules, requirement choices, prerequisites, regression tests, demonstration data and local setup. I used AI assistance during the portfolio review and preparation, including the independent synthetic test corpus, and validated the resulting changes locally.

## This public export

This repository is a reviewed export with one initial import commit. It imports existing team work and the later portfolio improvements. Its commit date marks preparation of this copy, not the original development of the application. The original source, complete recovered team Git repository and intermediate portfolio history remain in a separate restricted local archive. None of those Git objects or archive files were copied into this repository.

Permission was confirmed for team-written code, not instructor templates or university catalog content. I excluded the original instructor README, GitLab templates, attachment placeholders and historical configuration. The export contains independently written documentation, CI and text-file configuration. It also excludes the catalog-derived HTML/JSON snapshots and replaces the frontend's legacy catalog lists and policy examples with invented data.

The parser implementation is unchanged from the reviewed application. Its public regression corpus was authored from behavioral requirements using fictional rover, mural and workshop scenarios. The HTML, course codes, policy text and expected trees are original examples, not edits of university pages. [Parser testing](PARSER_REVIEW.md) explains the independent specification and coverage limits.
